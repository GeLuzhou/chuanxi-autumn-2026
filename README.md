# 一路向山 · 2026川西旅行地图

免费公开的 GitHub Pages 旅行网站：13 天行程、51 个地点（含 8 家已订酒店及停车换乘点）、21 张有来源和许可说明的实景参考照片。

## 浏览和相册

- 高德 JS API 2.0 提供标准地图、卫星地图（含道路名称），可在地图左上方切换，自动记住本设备的选择。切换不会重置当前日期和视野。
- 底图始终挂载，通过显示／隐藏切换，保留高德内部的文字标注层；不要使用 `map.setLayers()` 整组替换图层，否则会丢失城市名、道路名。
- 首次在每台手机／浏览器使用时，点击「导入地图配置」，选择私下收到的配置 JSON。之后浏览器直接连接高德，地图不再依赖 `chatgpt.site`。
- 在地图点选日期与景点，查看行程、景色特色和高德入口。
- 9 月 27 日成都市区游览；28 日大熊猫基地、晚间前往九寨沟；29 日九寨沟游览后回成都；10 月 4 日直接返回新都桥；10 月 5 日冷嘎措，不必等待日照金山。
- GitHub Pages 公开版不收集或存储用户上传的照片。「旅行相册」链接到原来的私人旅行手册，照片在那里上传、保存与管理，不会自动同步到公开网站。
- 自驾蓝色实线为高德规划的酒店—景点入口—酒店道路路线。9 月 30 日经双桥沟停车场；10 月 1 日只去中路藏寨，再经雅拉观景台、墨石公园、塔公；2 日经天路十八弯和理塘；6 日经 S434 红海子路段。日期卡片显示参考里程、驾驶时间；「分段导航」按游览顺序打开下一段高德导航，避免外部地图漏掉多个途经点。
- 10 月 3 日的扎西空墅在亚丁村内：自驾到游客中心停车场，再乘景区观光车入住；4 日先出沟取车，再自驾到瑞枫民宿。5 日从瑞枫往返帮木吉德方向的冷嘎措 A 线游客中心，不包含上山和湖边徒步；双桥沟观光车同样不计入自驾。其他交通虚线仍为行程示意。

## 本地运行

需要 Node.js 22.13 或更高版本。

```sh
npm ci
npm run dev
```

根目录部署用 `npm run build`。GitHub Pages 项目子路径由自动发布流程设置 `PAGES_BASE_PATH`。

## 发布

仓库 Settings → Pages → Source 选择 GitHub Actions。每次推送到 main，工作流会检查类型、构建静态网页并发布。页面浏览不需要 GitHub 或 ChatGPT 登录。

仅 `dist` 构建目录成为网站内容。公开源码和构建产物都不包含真实高德 Key 或安全密钥；不要将 `.env.local`、私密配置文件或密钥提交到 Git，也不要将安全密钥改成 `VITE_` 开头的变量。

## 本机地图配置

用户已选择本机导入方式：Key 与 `securityJsCode` 私下导入后存储在当前浏览器的 localStorage，由高德官方 JS API 直接使用。不再请求旧的境外代理或在线坐标转换服务。此模式不是服务端保密方案：设备使用者、本站同源脚本可以读取配置，加载地图时配置会传给高德；仅适合已接受这一取舍的小范围自用。

导入文件格式为 JSON，`format` 为 `chuanxi-amap-device-v1`，`key` 和 `securityJsCode` 为各自的 32 位十六进制值。文件中无法指定代理地址或脚本来源。配置通过隔空投送或其他私下方式传到手机，在网站「地图配置」中导入；也可在那里清除本机配置。更换浏览器、清除网站数据后需重新导入。请仅向信任的同行者传递文件，不要放入公开相册。

高德控制台请将 JS API Key 的域名白名单设置为 `geluzhou.github.io`；需要本地地图联调时再添加对应的本地测试域名。标准／卫星图层仍需联网，GitHub 页面自身的国内可达性依赖访问者网络。

## 资料与图片

行程、景点与入住日期位于 `lib/trip-data.ts`。原有 WGS84 示意坐标已通过高德官方 JS 坐标转换接口转换为 GCJ-02，结果保存在 `lib/trip-coordinates.json`。酒店与自驾景点的 `gcj02`、`navigationPosition` 来自高德 POI 位置和停车／换乘入口，不再二次转换。修改地点时需同步确认坐标系；`npm test` 检查所有地图点位的覆盖与酒店起终点。

`lib/driving-routes.json` 保存 2026-09-17 从高德官方驾车规划 API 取得的七天、十六段道路几何、距离和时间（GCJ-02，strategy=0）。每两个相邻停车入口单独规划，以 route.stops 和 segmentIds 保留途经顺序；地图逐段画道路，不用直线跨接景区内部或替代未获得的道路。里程和时间为各自驾段之和，景区内部观光车、换乘及徒步另计。冷嘎措已选 A 线，中路已确认，未选替代路线不打包发布。

浏览时不额外请求路径规划，公开数据不含 Key、安全密钥、订单图片或价格。路线为规划快照，不反映出发当日交通；导航链接只打开对应一段，与地图使用同一入口坐标。若更换酒店或景点入口，需同时更新入住表、POI、路段顺序与道路数据。`npm test` 检查入口、途经顺序、路线连续性、距离总和和各段导航链接；实际停车和通行按当天现场安排确认。

参考照片的来源、作者与许可位于 `lib/photo-credits.ts`，网站「关于」也能查看。照片根据其各自许可使用，不代表出行当日天气。贡嘎星轨照片仅为区域参考，并未确认具体湖名为冷嘎措。
