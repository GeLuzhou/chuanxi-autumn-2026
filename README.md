# 一路向山 · 2026川西旅行地图

免费公开的 GitHub Pages 旅行网站：13 天行程、42 个地点、21 张有来源和许可说明的实景参考照片。

## 浏览和相册

- 高德 JS API 2.0 提供标准地图、卫星地图（含道路名称），可在地图左上方切换，自动记住本设备的选择。切换不会重置当前日期和视野。
- 在地图点选日期与景点，查看行程、景色特色和高德入口。
- 9 月 27 日成都市区游览；28 日大熊猫基地、晚间前往九寨沟；29 日九寨沟游览后回成都；10 月 4 日直接返回新都桥；10 月 5 日冷嘎措，不必等待日照金山。
- GitHub Pages 公开版不收集或存储用户上传的照片。「旅行相册」链接到原来的私人旅行手册，照片在那里上传、保存与管理，不会自动同步到公开网站。
- 地图连线仅示意游览顺序，不是驾车导航或徒步轨迹。

## 本地运行

需要 Node.js 22.13 或更高版本。

```sh
npm ci
npm run dev
```

根目录部署用 `npm run build`。GitHub Pages 项目子路径由自动发布流程设置 `PAGES_BASE_PATH`。

## 发布

仓库 Settings → Pages → Source 选择 GitHub Actions。每次推送到 main，工作流会检查类型、构建静态网页并发布。页面浏览不需要 GitHub 或 ChatGPT 登录。

仅 `dist` 构建目录成为网站内容。高德 JS Key 从地图服务的 `/config` 获取，是浏览器必需的公开标识；`securityJsCode` 只存放在独立地图服务的运行时 Secret 中。前端使用高德官方 `serviceHost` 代理方式，不打包安全密钥，也不把 `.env.local` 提交到 Git。

地图服务仅代理本网站需要的地图鉴权、样式和坐标转换接口，限制来源和请求频率。高德控制台请将 JS API Key 的域名白名单设置为 `geluzhou.github.io`。不要将安全密钥改成 `VITE_` 开头的变量。

本地开发可通过同样的代理服务测试；生产代理默认仅接受正式网站来源。若需本地联调，服务端可临时配置 `ALLOW_LOCAL_PREVIEW=true`，允许 `http://127.0.0.1:5173` 和 `http://localhost:5173`，并在高德控制台允许对应测试域名。

## 资料与图片

行程和景点内容位于 `lib/trip-data.ts`，原有 WGS84 示意坐标通过高德官方接口转换为 GCJ-02 后绘制。参考照片的来源、作者与许可位于 `lib/photo-credits.ts`，网站「关于」也能查看。照片根据其各自许可使用，不代表出行当日天气。贡嘎星轨照片仅为区域参考，并未确认具体湖名为冷嘎措。
